# GoIT JS Homework 05 - Iterating Array Methods & Chaining
JavaScript homework assignment for the GoIT course (Module 5). Topic: working with iteration array methods (`map`, `filter`, `toSorted`, `reduce`), arrow functions, and method chaining.

**What was done:**
- Set up the repository `goit-js-hw-05` and configured the project structure according to the course requirements
- **Task 1 (User Names):** Implemented the arrow function `getUserNames` using the `map()` method to extract an array of all user names from the user objects
- **Task 2 (Users with a Friend):** Implemented the arrow function `getUsersWithFriend` using `filter()` and `includes()` to find and return users who have a specific friend in their `friends` list
- **Task 3 (Sort by Friend Count):** Implemented the arrow function `sortByDescendingFriendCount` using the modern `toSorted()` method to sort users in descending order based on the number of friends they have
- **Task 4 (Total Balance by Gender):** Implemented the arrow function `getTotalBalanceByGender` using a method chain (`filter` and `reduce`) to calculate the total balance of users filtered by a specific gender
- Verified code formatting with Prettier and ensured zero errors or warnings in the browser console across all tasks via GitHub Pages
